# Megabonk Rails Builder

A BepinEx mod for **Megabonk** that adds a dedicated build mode for placing rails with precision.
It includes ghost previews, rotation, flipping, and a freeze mode that stops time and enemy spawns, letting you build without interruptions.

### For MelonLoader version go to [Megabonk Rails Builder Melon](https://github.com/svind1er/MegabonkRailsBuilderMelon)
---

## ✨ Features
- **Build Mode** (toggle with `F1`)
- **Ghost Preview** of rails before placement
- **Rotation** (hold `Q` / `E` or press `Z` / `X` for 90° snaps, `C` to reset)
- **Flip** rails horizontally (`F`)
- **Freeze Mode** (`F2`)
  - Pauses timers
  - Blocks enemy spawns
  - Lets you build in peace

---

## 🎮 Controls
- `F1` – Toggle Build Mode
- `F2` – Toggle Freeze Mode
- `←` / `→` – Switch rail type
- `Q` / `E` – Rotate smoothly
- `Z` / `X` – Snap rotate 90°
- `C` – Reset rotation
- `F` – Flip rail
- `LMB` – Place rail

---

## 📦 Installation
1. Install **BepInEx** into your game.
2. Download the latest release of **Megabonk Rails Builder**.
3. Drop the `.dll` file into your game’s `BepInEx/plugins` folder.
4. Launch the game and press `F1` to enter Build Mode.
